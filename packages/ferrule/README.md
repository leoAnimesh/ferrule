# ferrule

React Native UI components you copy into your app and own, for iOS, Android and web. This package holds the provider, the theme, the primitives, the `ferrule` CLI, and the component registry that `ferrule add` copies from.

Docs: https://leoanimesh.github.io/ferrule/. Source: https://github.com/leoAnimesh/ferrule.

```sh
npx ferrule init --fix
npx ferrule add button input
```
